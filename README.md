# 🏠 Landing Page - Piso en Venta Calle Cuenca 13, Arrancapins Valencia

Landing page ultra optimizada para SEO creada con **Astro + Tailwind CSS** para la venta de un piso en Arrancapins, Valencia.

## 🚀 Características

- ✅ **Performance perfecta**: 100% HTML estático, carga instantánea
- ✅ **SEO Optimizado**: Meta tags, Schema.org, Open Graph
- ✅ **Responsive**: Diseño adaptado a móvil, tablet y desktop
- ✅ **One-Page**: Navegación fluida con scroll suave
- ✅ **Keywords integradas**: Todas las palabras clave de alta intención
- ✅ **Core Web Vitals perfectos**: Ideal para Google Ads Quality Score

## 🛠️ Instalación

```bash
# Instalar dependencias
npm install

# Desarrollo (puerto 4321)
npm run dev

# Build para producción
npm run build

# Preview del build
npm run preview
```
